Owner Settings page at `/settings` (`src/pages/Settings.tsx`):
- Accordion sections: Company Info (name, phone, email, address, category, currency, timezone, copy-to-clipboard company code), Working Hours (per-day open/close + closed checkbox stored as JSONB `working_hours`), Booking Preferences (deposit min £10, auto_confirm, allow_same_day, buffer_minutes, max_advance_days, cancellation_hours), Notifications (4 toggles), Booking Page (welcome_message, accent_color), Danger Zone (Reset Password works, Log Out works, Delete Account disabled).
- Single "Save All Changes" upserts the whole `business_settings` row.
- Theme + Language deliberately omitted (dark only for now).
- Linked from Dashboard header (replaced old `BusinessSettingsDialog`, which was deleted).

Company code:
- Auto-generated by `generate_company_code()` SQL function (format `BS-XXXXXX`, alphabet excludes I/O/0/1).
- Default on `business_settings.company_code`; backfilled for existing rows.
- Auto-created with a default `business_settings` row by `handle_new_user()` trigger (skipped when signup metadata `role = 'employee'`).

Employee join flow:
- Landing page `<JoinCompanyDialog>` button next to "Try now" / "Pricing".
- Flow: signUp with `data:{role:'employee'}` → look up business by `company_code` → require existing `employees` row matching email → set `employees.auth_user_id = newUserId` → redirect to `/employee-dashboard`.
- `routeAfterAuth.ts` decides post-login redirect by checking `employees.auth_user_id = auth.uid()`.

Employee dashboard at `/employee-dashboard` (`src/pages/EmployeeDashboard.tsx`):
- Shows company name + employee name + upcoming bookings list (read via new RLS policy "Employees can view company bookings").

Widget (`src/lib/widgetTemplate.ts`) now reads `working_hours` per-day, hides closed days, respects `allow_same_day`, `max_advance_days`, `buffer_minutes`, and shows `welcome_message`.
